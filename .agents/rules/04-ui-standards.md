# 04. UI Standards

- **Typography:** Gunakan `GoogleFonts.plusJakartaSansTextTheme()`.
- **Colors:** Patuhi `SolluColors` (Primary Navy Blue #1e40af, Secondary Turquoise #06b6d4).
- **Styling:** 
  - Border radius 12px untuk input/tombol, 20px untuk cards/dialogs.
  - Shadow sangat tipis (ambient shadow) menggantikan material elevation.
- Sesuaikan desain dengan versi web Vue, namun optimalkan secara responsif untuk layar sentuh (tablet/mobile Android) serta layar desktop (macOS & Windows) menggunakan *Adaptive UI*.
