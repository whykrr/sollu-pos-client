# 07. Git & Changelog

- Gunakan format **Conventional Commits** (feat, fix, refactor, chore, dll).
- Selalu patuhi **SemVer** saat melakukan rilis versi di `pubspec.yaml`.
- Branching: `feature/nama-fitur`, `bugfix/nama-bug`.
- **MCP Integration:** Agen AI wajib menggunakan `git` MCP untuk operasi repositori seperti `status`, `commit`, memeriksa `branch`, dan manipulasi riwayat git alih-alih menggunakan command terminal secara langsung, guna menjaga stabilitas history.
