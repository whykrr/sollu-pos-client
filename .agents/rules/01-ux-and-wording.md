# 01. UX & Wording untuk POS Client

- **Tap Targets:** Minimal 48x48 dp untuk semua tombol interaktif, karena digunakan di lingkungan kasir yang butuh kecepatan.
- **Offline States:** Berikan indikator visual yang jelas saat perangkat kehilangan koneksi (misal, badge merah di header).
- **Kecepatan Transaksi:** Hindari loading screen panjang. Gunakan optimistik UI untuk *add to cart* atau proses bayar.
- **Wording:** Singkat, jelas, profesional. Hindari jargon teknis (gunakan "Gagal menyimpan data" alih-alih "Error 500").
